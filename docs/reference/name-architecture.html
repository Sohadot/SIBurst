Conceptual foundation

Name Architecture

This is the canonical semantic architecture of the name SIBurst. Other foundation documents refer to these definitions; they do not redefine them.

SI

Superintelligence, within the SIBurst identity.

"SI" is used intentionally inside this naming system to denote superintelligence: intelligence that greatly exceeds human cognitive performance across a broad range of domains (see GLOSSARY.md for the governed definition and the variation in how the term is used).

SIBurst makes no claim that "SI" is the exclusive, universal, or canonical abbreviation for superintelligence. The letters carry other meanings in other fields. Within this identity, and only within it, SI means superintelligence.

Using the term as part of a name is not a claim that superintelligence exists. SI names the direction of the transition, not a system that has arrived.

Burst

Discontinuity, release, or transition after accumulated capacity.

Within SIBurst, "burst" denotes:

  • discontinuity — the previous description stops being adequate;
  • threshold crossing — accumulated capacity passes a condition that changes how it behaves;
  • qualitative regime change — the system enters a different mode of operation, not a faster version of the old one.

The image is of something held and then released: capacity that builds up under one set of rules and is expressed under another.

"Burst" in SIBurst is explicitly not:

Not this Why not
A temporary benchmark spike A spike returns to baseline. A regime change does not.
Burst performance or peak throughput That is more of the same, briefly. SIBurst concerns a change in kind.
An explosion Explosions destroy structure. A phase change reorganizes it.
Speed Rate of change is not the point; change of regime is.
Hype The word marks a boundary, not an intensity of excitement.

SIBurst

Canonical definition:

SIBurst is the identity for the transition from incremental intelligence growth into a materially different operating regime.

Operationally, SIBurst names the transition event at which intelligence can no longer be understood only as more incremental capability, but enters a materially different operating regime.

The name refers to the transition, not to either side of it. It is neither the capability that came before nor the system that comes after. It is the crossing.

Semantic layer

Superintelligence + discontinuity.

SI supplies the domain: intelligence at and beyond the frontier of capability. Burst supplies the event: a discontinuous crossing. Together they name the point where the domain changes regime.

Temporal layer

BEFORE  →  THRESHOLD  →  TRANSITION  →  AFTER
  • Before: capability accumulates; quantitative description is adequate.
  • Threshold: conditions emerge under which accumulation stops producing same-kind effects.
  • Transition: the SIBurst itself — the previous description fails.
  • After: a new operating regime, with its own rules, requirements, and governance.

The temporal layer is a structure, not a schedule. It carries no dates.

Commercial layer

A name capable of sitting above organizations, systems, and infrastructure concerned with frontier capability, autonomy, inference, agents, compute, evaluation, or transition monitoring.

The strength of SIBurst is not that it describes one AI product. It describes a transition that many different systems may attempt to enable, measure, govern, or respond to.

The commercial layer is described in full in COMMERCIAL_TERRITORY.md; its limits are set in CATEGORY_BOUNDARY.md.

Usage rules

  • Write SIBurst as one word, with "SI" capitalized and "Burst" in title case.
  • Use "burst" in running text only in the sense defined above.
  • Do not use SIBurst as a synonym for superintelligence itself. SIBurst is the transition; superintelligence is one possible description of what lies beyond it.
  • Do not describe the name as unique, superior, or inevitable. Describe what it names.
